# GreatX Labs

Bienvenido a la organización de GreatX Labs. Aquí se encuentra el código fuente de nuestros proyectos principales, sistemas y demos técnicas.

## Proyectos

### Ikaros
Ikaros es un sistema de relevo de información y gestión basada en roles para misiones espaciales.
- [**ikaros-server**](https://github.com/GreatXLabs/ikaros-server) - Backend desarrollado en Java y Spring. Incluye un protocolo TCP propio, control de acceso por roles (RRHH, Coordinador, Asignador, Registrador, Jefe) y persistencia en MariaDB.
- [**ikaros-client**](https://github.com/GreatXLabs/ikaros-client) - Frontend en React (JavaScript) para interactuar con el sistema Ikaros.

### Demos y otros
- [**java-mutex-concurrency-demo**](https://github.com/GreatXLabs/java-mutex-concurrency-demo) - Comparación visual sobre condiciones de carrera y su protección usando Mutex (Semáforos) en Java.
- [**frontend-trust-issues**](https://github.com/GreatXLabs/frontend-trust-issues) - Entorno de pruebas y desarrollo frontend en TypeScript.

## Stack Tecnológico
La mayor parte de nuestro desarrollo se basa en:
- **Backend:** Java, Spring, MariaDB
- **Frontend:** JavaScript, TypeScript, React
